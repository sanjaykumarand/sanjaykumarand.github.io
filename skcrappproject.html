SK Classroom App

A desktop classroom application built with JavaFX and Java Swing.

Creating this app includes JavaFX, JDK, Inno Setup Wizard, and Advanced Bat To Exe Converter — it needs an active website to run the application smoothly.

Swing AWT JavaFX.web JavaFX.swing

JDK and JavaFX commands were stored in a .bat file, which was then converted into a .exe file for a smooth app experience.
