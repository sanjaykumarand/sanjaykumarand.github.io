FileToolBox App

A GUI-based console application built with Java Swing.

The FileToolBox App is a GUI-based console application with the following features:

📄 Creating a New File

⌨️ Writing a File

📖 Reading a File

🔒 Encrypting File

🔓 Decrypting File

📜 Exporting to CSV

🔍 Scan Directory

📁 File MetaData

🌙 Dark Mode
